# Analog sizing benchmark

`manifest.json` is the versioned cross-project contract generated by
TopologyLantern. Its provenance, MIT license, deterministic generation command,
expected metrics, and canonical SHA-256 are embedded in the manifest. The file
and its public schema are byte-for-byte producer copies; BiasWeave does not
rewrite their provenance.
The public Draft 2020-12 schemas under `docs/schemas/` describe the producer
contract and downstream sizing decision. Runtime loading additionally rejects
duplicate keys, non-finite values, digest mismatches, invalid bounds, and
decisions that do not replay to the complete seeded comparison.

Run the same-budget comparison:

```console
biasweave benchmark --contract benchmarks/manifest.json --budget 64 --seed 17
```

The comparison reports evaluations, unique points, feasible points, Pareto
front size, and per-objective extrema for BiasWeave and seeded uniform random
search. It is descriptive and makes no statistical or state-of-the-art claim.
The representative uses equal normalized L1 objective contributions over the
observed feasible Pareto front. A sizing-decision export replays the complete
seeded comparison before binding the selected point to its comparison digest.

`python benchmarks/scaling.py --budgets 16,64,256 --repetitions 3 --seed 17`
records workload/environment hashes and same-budget invariants at increasing
evaluation counts. Budgets and repetitions are bounded integers, and seeds use
the portable signed 64-bit integer range. The timing and throughput fields are
descriptive and are not acceptance thresholds. Each report identifies the installed
distribution, imported Python package tree, and exact scaling harness by content hash.
